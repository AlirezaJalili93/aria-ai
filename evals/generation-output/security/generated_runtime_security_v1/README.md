# Generated Runtime Security Corpus v1

Synthetic adversarial mutations for `0098-generated-runtime-security-review`.

- The corpus contains no Customer Content, credential or Provider response.
- `accepted_as_inert_text` means the value may survive validation only as escaped text and must
  never create markup, code execution or a network request.
- `rejected` means the frozen Generation AST/Application validation boundary must fail closed.
- Changes to the cases or semantics require a new suite version.
